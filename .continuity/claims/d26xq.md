A C for Continuity drawn as a single unbroken arc — the thread that survives between sessions — terminating in a filled node, one captured claim. Gradient #6366F1 -> #8B5CF6. This replaces the earlier two-colour palette rule where slate meant 'superseded'; the mark no longer encodes that distinction.

Files: assets/mark.svg (26px inline glyph), assets/icon.svg (rounded tile for repo avatar/favicon), assets/logo-light.svg + logo-dark.svg (181x48 lockups, selected by prefers-color-scheme). README hero renders at 180px. SVG-only and in-repo per c1, ~3.3KB total.

Lockup alignment is computed, not eyeballed, and must stay that way if the mark is re-scaled: the arc sweeps the LONG way round, so the right-hand ink extreme is the node, not the circle. Ink spans x 24.6..80.5, y 15.5..79.5 in the 96 box; after scaling it is translated so the ink centre and the text cap-centre both land on y=24. Before that fix the mark rode ~4px high.

Known and accepted: the mark is a C and the wordmark starts with C, so the lockup reads faintly as 'C Continuity'. Judged acceptable; the fallback is to drop the mark from the lockup and keep it standalone.
