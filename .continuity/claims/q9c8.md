Axis 1, extraction: did we derive the right fact from a messy session? Axis 2, authority: had that fact earned the right to become durable project state at all?

A system can be perfect on axis 1 and still be wrong, because it recorded something true-as-discussion as true-as-project. Demonstrated live on 2026-09-03: five turns designed an evaluation in implementable detail, two advisors agreed on nearly all of it, and a naive memory system would have recorded 'user is building ContinuityBench, Suite A, five scenarios, three repetitions'. Every one of those sentences was correctly extracted and false as project truth, because the owner never approved it.

The ladder that matters: discussion -> candidate -> proposal -> OWNER COMMITMENT -> durable state. Only the last transition earns a claim. Volume of discussion is not evidence of decision, and agreement between AIs is not approval.

This is a question, not a plan: no evaluation is approved, and this claim must not be read as one.
