Project-scoped hooks in .claude/settings.json run the repo's own committed dist/ bundles through $CLAUDE_PROJECT_DIR, so a collaborator who only runs `git clone` gets auto-resume and auto-capture without installing the plugin. Developers who ALSO have the plugin installed register the same hooks twice, so both hooks de-duplicate per session via src/core/once.ts (SessionStart drops a duplicate within 5s; Stop already had a 10s throttle serving as its loop backstop). Self-activation and plugin install are therefore complementary, not alternatives.
