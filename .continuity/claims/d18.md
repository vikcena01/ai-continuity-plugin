CLAIM_TYPES is the runtime source of truth and ClaimType is derived from it, so the list and the type cannot drift. The reconciler maps obvious near-misses (open_question→question, rejected→rejected_alternative) and rejects any other string with a note naming the valid types; nextId throws rather than deriving a prefix from an unknown type. Guessing at types is exactly what caused rk1 — a bare `as ClaimType` cast let 'open_question' through and minted ids like ope1 — so the fix is to keep the vocabulary closed rather than to guess harder.
