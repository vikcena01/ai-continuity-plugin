The server page renders this repo's README. So BOTH of these mislead:
  - the 'Latest release' field, which shows the README's status line verbatim rather than a release number;
  - any substring search over the page HTML for tool names, because the README's own tool list names all of them.

Correct method: open /mcp/servers/<owner>/<repo>/schema and read the enumerated tool listing, which comes from the deployed server. 11 tools = 1.1.x, 12 = 1.3.0, 13 = 1.4.0 with search_claims.

This was recorded, then violated one turn later by changing method from reading the listing to grepping the page. The rule is not 'count tools' — it is 'read the schema page'.
