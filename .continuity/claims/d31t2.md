Anthropic runs TWO marketplaces. `claude-plugins-official` is curated at Anthropic's discretion with NO application process — submissions never reach it. `claude-community` is the public marketplace where third-party submissions land after review; users add it with `/plugin marketplace add anthropics/claude-plugins-community` and install from `@claude-community`.

Submission forms, and the choice matters: claude.ai/admin-settings/directory/submissions/plugins/new requires a Team or Enterprise organisation with directory-management access, so it is the WRONG one here — using it would route this personal project through the work org, against c5hi. Individual authors use the Console form at platform.claude.com/plugins/submit.

Pre-flight: `claude plugin validate .` runs the same check as the review pipeline plus automated safety screening. Verified passing for this repo on 2026-08-26 ('Validation passed'). The documented --strict flag is not in the installed CLI yet; harmless, since warnings do not fail validation.

After approval the plugin is pinned to a specific commit SHA in anthropics/claude-plugins-community and their CI bumps the pin as commits are pushed; the public catalogue syncs nightly, so expect a delay before it is installable. Meanwhile the self-hosted route still works unchanged: `/plugin marketplace add vikcena01/ai-continuity-plugin` then `/plugin install continuity@continuity-marketplace`.
